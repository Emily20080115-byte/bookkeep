# 小錢包記帳

用錢包插圖當圖示的記帳 App（PWA），可以加到手機主畫面，像一般 App 一樣開啟。

## 功能
- 記錄支出 / 收入，選分類、日期、備註
- 每月結餘、收入、支出總覽，可切換月份
- 支出分類統計長條圖
- 點明細可修改或刪除
- 匯出 / 匯入備份（JSON）
- 離線也能用，資料只存在你的手機上

## 安裝到主畫面
1. 到 repo 的 **Settings → Pages**，Source 選 `main` 分支（或此分支）的根目錄，按 Save
2. 用手機開啟產生的網址
   - iPhone：Safari → 分享按鈕 → 「加入主畫面」
   - Android：Chrome → 選單 → 「安裝應用程式」/「加到主畫面」
3. 主畫面就會出現錢包圖示，點開會先看到錢包開啟畫面
